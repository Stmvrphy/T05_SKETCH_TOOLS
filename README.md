# Heavy Metal Song - Sebastian Murphy (Lyric Visualizer)
An interactive video lyric visualizer built for Sebastian Murphy's Heavy Metal track, exploring the contrast between classic composition and dark visual themes.

## Concepto
-**Sonido inspirado en The Beatles:** Basado en una estructura musical directamente influenciada por los primeros discos de The Beatles.
-**Imaginería Metal y oscura:** Combinado con letras, iconografía y elementos visuales arraigados en el Heavy Metal y la estética oscura.
-**Fusión de estilos:** Una dirección visual que combina estéticas vintage, modernas y alternativas.

# Audio-Reactive Liquid Splatter Tool

Una herramienta visual interactiva para la web construida con HTML5 Canvas y la API de Web Audio que genera salpicaduras líquidas dinámicas (como tinta o sangre) en respuesta al sonido.

## Características

- **Salpicaduras Reactivas al Audio:** Genera manchas, gotas y chorros de líquido activados por audio en vivo (micrófono) o archivos de música subidos.
- **Apariencia Personalizable:** Alterna entre un estilo plano 2D y un modo texturizado con sombra paralela, profundidad y relieves.
- **Ajuste de Salpicadura:** Controla la cantidad de líquido, cambia entre manchas grandes acumuladas o un spray de puntos finos, y ajusta la expansión desde los bordes del lienzo.
- **Modo de Acumulación:** Elige si las manchas se acumulan de forma permanente en la pantalla o si desaparecen gradualmente tras un segundo.

## Tecnologías Utilizadas

- **HTML5 Canvas** (Renderizado 2D)
- **Vanilla JavaScript**
- **Web Audio API** (`AudioContext`, `AnalyserNode`)

## Notas de desarrollo
**Prototipo de herramienta HTML** (Descartado)
Se creó una herramienta HTML independiente inicial para explorar parámetros de visualización personalizados más allá de las opciones proporcionadas por SketchTools (CRT).
**Razón del descarte:** La herramienta personalizada añadió complejidad al flujo de trabajo general sin aportar un valor significativo ni una mejora visual relevante en comparación con la implementación integrada de SketchTools.
