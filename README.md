# Audio-Reactive Liquid Splatter Tool

Una herramienta visual interactiva para la web construida con HTML5 Canvas y la API de Web Audio que genera salpicaduras líquidas dinámicas (como tinta o sangre) en respuesta al sonido.

## Características

- **Salpicaduras Reactivas al Audio:** Genera manchas, gotas y chorros de líquido activados por audio en vivo (micrófono) o archivos de música subidos.
- **Apariencia Personalizable:** Alterna entre un estilo plano 2D y un modo texturizado con sombra paralela, profundidad y relieves.
- **Ajuste de Salpicadura:** Controla la cantidad de líquido, cambia entre manchas grandes acumuladas o un spray de puntos finos, y ajusta la expansión desde los bordes del lienzo.
- **Modo de Acumulación:** Elige si las manchas se acumulan de forma permanente en la pantalla o si desaparecen gradualmente tras un segundo.
